## Uso recomendado

1. Usar el CSV como registro maestro de control documental.
2. Filtrar primero por `prioridad_preliminar = Alta` y extensiones `PDF`, `XLSX`, `DOCX`.
3. Abrir comprimidos solo cuando sean necesarios para resolver obligaciones, anexos o respaldos no disponibles como archivos extraidos.
4. Actualizar `estado_revision` y `notas` a medida que se generen resumenes o se detecten brechas.
5. Vincular cada obligacion extraida con el `id` del archivo fuente.
